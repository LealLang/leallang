# console

The `console` namespace provides output functions.

## print_ln

Prints a value followed by a newline.

```python
console.print_ln("Hello, world")
console.print_ln(42)
console.print_ln($"Key: {key}, Value: {value}")
```

## print

Prints a value without a newline.

```python
console.print("This is a message without a newline. ")
```
