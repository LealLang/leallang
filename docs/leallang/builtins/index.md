# Built-in Namespaces

LealLang provides several built-in namespaces for common operations.

| Namespace | Purpose |
|-----------|---------|
| [console](console.md) | Print output to console |
| [file](file.md) | File system operations |
| [window](window.md) | Window management |
| [msg](msg.md) | Message dialogs |
| [json](json.md) | JSON parsing and serialization |
| [modal](constants.md#modal) | Modal dialog management |
| [toast](constants.md#toast) | Toast notifications |

## Constants

| Namespace | Purpose |
|-----------|---------|
| [colors](constants.md#colors) | Color constants |
| [dock](constants.md#dock) | Docking positions |
| [orientation](constants.md#orientation) | Layout orientations |
| [toast_type](constants.md#toast_type) | Toast notification types |
